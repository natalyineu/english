📖 Key Rules — Conditionals (click to expand)
TypeStructureUse
Type 0If + present simple, present simpleGeneral truths, scientific facts
Type 1If + present simple, will + infinitiveReal or likely future situations
Type 2If + past simple, would + infinitiveUnreal or unlikely present/future
Type 3If + past perfect, would have + past participleUnreal past situations
MixedIf + past perfect, would + infinitiveUnreal past → present result

Type 0: If you heat ice, it melts.

Type 1: If it rains tomorrow, we will stay indoors.

Type 2: If I were you, I would apologise. (Note: were for all persons)

Type 3: If she had left earlier, she would have caught the train.

Mixed: If he had studied medicine, he would be a doctor now.

⚠️ Never use will or would in the if-clause (except for polite requests: "If you would kindly wait…").
